# DesignRxUIKit Scope

## Ownership
- Sources/UIKit+Rx/BaseBlocks: ViewModel/controller/navigator blueprints and
  UseCase, CompletableUseCase, StreamUseCase contracts.
- View: Driver-based component bindings and view-specific conveniences.
- Rx+: transforms and ErrorTracker.

## Contracts
- Preserve Driver-based, UI-safe binding behavior.
- Keep UIView disposeBag associated-object-backed and tied to view lifetime.
- Preserve ErrorTracker forwarding source errors into its internal stream.
- Keep completeDriver conversion non-throwing and operator semantics stable.
- Avoid blocking or synchronous work in binding/transform helpers.
- FButton+Rx has title binding and onTap(trigger:), but no action-closure
  convenience initializer. Retained tvOS guards do not imply platform support.
- BaseBlocks are architecture contracts; concrete use cases belong in consumer
  feature/domain modules and are injected; a ViewModel can own several.
- Preserve public source compatibility and avoid Archived APIs.

- Named subscriptions support scoped replacement/cancellation; see [ownership](../1.1.0/04_BINDINGS.md).

## Usage
```swift
label.bind(to: titleDriver) { label, title in
    label.text = title
}
```
