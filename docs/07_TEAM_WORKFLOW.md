# Team Workflow

## Source of Truth
- Working agreement: [AGENTS.md](../AGENTS.md).
- Ownership: [architecture](11_ARCHITECTURE.md) and [module scopes](modules/00_INDEX.md).
- Durable decisions: [decision log](06_DECISIONS.md).
- Progress: [roadmap](05_ROADMAP.md) and [status](09_STATUS.md).

## Task Checklist
- [ ] Read the root agreement, index, and relevant module scope.
- [ ] Inspect current code and existing tests before changing behavior.
- [ ] Use a focused branch when requested; keep unrelated work intact.
- [ ] Write task and acceptance lists with Markdown checkboxes.
- [ ] Keep reactive concerns and business logic within their documented boundaries.
- [ ] Update relevant documentation as each task or milestone completes.
- [ ] Run appropriate validation and review the diff.
- [ ] Mark only completed checks; explain remaining verification.

## Handoff Checklist
- [ ] State the changed behavior and owning module.
- [ ] Link maintained documentation for decisions or ongoing work.
- [ ] Report validation performed and any limitations.
- [ ] Keep pending work unchecked and avoid claiming proposed behavior exists.
