# Continuous Integration

## Triggers and Jobs
- Display name: iOS and Mac Catalyst CI; entry point: .github/workflows/ci.yml.
- CI runs for same-repository PRs into master/release branches, pushes to those
  branches, and manual dispatch. Fork PRs do not execute on the personal runner.
- Documentation → iOS tests/examples → Catalyst tests run sequentially.
- iOS uses an isolated simulator on the newest installed runtime supported by Xcode.
- Catalyst runs both package tests and hosted UIKit tests for responder coverage.
- Guide examples typecheck independently using the iOS test build's modules.
- Failure logs and xcresult bundles are uploaded with seven-day artifact retention.
- New commits cancel obsolete CI for the same PR/ref; jobs have timeouts.

## Existing Runner Requirements
- All jobs require self-hosted, macOS, ARM64, mini labels.
- Dukes-Mini is an organization runner shared with DesignUIKit (confirmed in UI).
- No runner is installed or registered by this change.
- Checkout uses the verified v6 commit with credentials persistence disabled.
- Checkout v6 requires runner version 2.327.1 or later.
- Xcode, Python 3, Git, an installed iOS simulator, and an active macOS login
  session for Catalyst window tests are required under the runner account.
- Each job uses its own temporary build directories and deletes only its simulator.
- One runner service executes one job at a time; avoid multiple services sharing
  the same checkout or simulator data on the mini.
- Checkout credentials are not persisted; token permissions are contents: read.

## Manual Release Verification
- Choose Release verification in Actions after this workflow reaches master.
- Supply a full trusted release commit SHA that includes these CI scripts.
- It runs the same checks at that commit and records the verified SHA.
- It does not create tags or publish packages; those remain separate actions.

## Local Commands
```sh
python3 scripts/ci/check_docs.py
python3 -m unittest discover -s scripts/ci -p 'test_*.py'
python3 scripts/ci/run_tests.py ios --work-dir /private/tmp/designuikit-ios-unique
python3 scripts/ci/run_tests.py catalyst --work-dir /private/tmp/designuikit-mac-unique
```
